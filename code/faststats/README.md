# FastStats

A minimal mixed Python and Rust project demonstrating:

- a Python-facing public API
- a pure Rust calculation engine
- PyO3 bindings
- maturin packaging
- Rust unit tests and Python integration tests

## Project layout

```text
faststats/
├── Cargo.toml
├── pyproject.toml
├── README.md
├── python/
│   └── faststats/
│       ├── __init__.py
│       ├── api.py
│       ├── py.typed
│       └── _core.<platform-extension>  # generated by maturin
├── src/
│   ├── lib.rs
│   └── summary.rs
└── tests/
    └── test_faststats.py
```

The generated extension is usually a `.so` file on macOS and Linux and a
`.pyd` file on Windows. Its full filename includes Python and platform tags.

## Prerequisites

- Python 3.10 or later
- Rust 1.83 or later
- `uv`, or another Python environment manager

## Build for local development

```bash
uv sync
uv run maturin develop
```

## Try it

```bash
uv run python -c 'from faststats import summarize; print(summarize([10, 20, 30]))'
```

Expected output:

```text
Summary(count=3, sum=60, mean=20, minimum=10, maximum=30)
```

## Run tests

Rust unit tests:

```bash
cargo test
```

Python integration tests:

```bash
uv run pytest
```

## Build a wheel

```bash
uv run maturin build --release
```

The wheel will be created under `target/wheels/`.
